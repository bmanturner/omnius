# Audience and end-to-end journey map

This page is a route map, not runtime evidence. A specification, selected profile, generated artifact, catalog entry, or library implementation does **not** prove that a concrete application exposes a capability. Each step therefore names its strongest current evidence boundary: `assembled`, `generated-only`, `library-only`, `unassembled`, or `not-applicable`. Implementation qualifiers such as `partial`, `source-only`, `specified-only`, and `unavailable` are included where they change what the reader can expect.

Paths below are canonical documentation destinations. Follow the [capability coverage matrix](coverage-matrix.md) for the source evidence and current classification behind every claim. Use only the glossary candidates owned by [the evidence inventory](evidence-inventory.md#canonical-terminology-and-glossary-candidates); this page does not redefine them.

## Audiences
